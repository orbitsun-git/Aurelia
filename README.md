# Aurelia 整理版 / 정리본

기존 R7 코드 기반. 루트 중복 이미지와 이전 배경 폴더를 제거하고, 기존 코드의 배경 참조를 assets/themes100-preview 한 곳으로 통일했습니다. 동일 이미지 중복도 경로 공유로 제거했습니다. 이미지 축소·재압축은 하지 않았습니다.

정리 전 71.5 MB → 정리 후 약 30.4 MB (압축 전).

## 구조
- assets/: 현재 배경·로고
- js/, css/, api/: 사이트 코드
- data/, scripts/, .github/: 뉴스·자동갱신 유지
- setup/: 기존 SQL 보관. 전부 다시 실행하지 마세요. R6 미적용 시 해당 안내만 따르세요.
- docs/: 사용 안내와 이미지 제작 상태

## 중요: 기존 GitHub 파일 삭제는 자동이 아닙니다
이 ZIP을 웹에서 업로드/덮어쓰기만 하면 기존의 불필요 파일은 남습니다. DELETE_OLD_PATHS.txt는 정리본 기준으로 제거하거나 이동한 기존 경로입니다. GitHub 백업 후 목록의 파일만 삭제하거나, 로컬 Git 저장소에서 기존 추적 파일을 정리본과 동기화해 삭제 사항까지 커밋해야 합니다. .git 및 본인의 js/config.js는 보존하세요. 비밀 키는 업로드 금지.

GitHub 원격 저장소는 변경하지 않았습니다. 제공 파일은 정리된 전체 코드입니다. 이전 assets/themes 폴더는 이 정리본 전체를 적용하면 불필요합니다. 이전 R6/R7 코드만 적용된 상태에서 먼저 폴더를 지우지는 마세요.

100개 배경 대부분은 작은 시안을 분할한 이미지이며 고해상도 완성본이 아닙니다. 기능/디자인 수준은 R7과 동일합니다. 실제 브라우저·배포·로그인·저장 테스트는 미실행. JS 문법, 정적 이미지 참조 및 100×4 배경 경로와 ZIP만 검사했습니다.
