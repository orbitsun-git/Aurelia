# Aurelia 전체 교체 안내

## 먼저 확인
- 기존 Aurelia 폴더를 백업하세요. 기존 supabase 폴더와 기존 서버 데이터는 삭제하지 마세요.
- 이 묶음은 최신 디자인에 맞춘 재작성 버전입니다. 기존 코드의 완벽한 호환 패치가 아닙니다.
- 관리자 진입 버튼은 홈에만 있습니다. 페이지를 숨기는 것과 별개로 쓰기 권한은 서버 RLS가 확인합니다.
- 기존 자료 테이블을 건드리지 않도록 aurelia_ 접두사의 새 테이블을 사용합니다. 기존 강의/자료는 자동 이전되지 않습니다.

## 1. 파일 배치
ZIP 안의 Aurelia/ 내용물을 현재 VS Code의 Aurelia 폴더 안에 복사하세요. Aurelia/Aurelia로 중첩하지 마세요.
동일 파일은 백업 후 교체하고, assets의 다른 이미지와 supabase 폴더는 유지하세요.

```
Aurelia/
  index.html
  subject.html
  server-setup.sql
  README.md
  news-sources.json
  css/style.css
  js/config.js
  js/backend.js
  js/main.js
  js/admin.js       (미사용 표시)
  js/subject.js     (미사용 표시)
  js/ai-helper.js   (미사용 표시)
  assets/themes/   (도시·비행기 원본 8장 + 임시 추상 풍경)
  data/news.json
  scripts/update_news.py
  .github/workflows/daily-news.yml
```

## 2. Supabase 설정
1. js/config.js의 두 빈 값에 프로젝트 URL, publishable 또는 anon 공개 키를 입력하세요. secret/service_role 키는 브라우저에 넣지 마세요.
2. SQL Editor에서 server-setup.sql 전체를 실행하세요. 새 테이블 3개와 RLS 정책을 만듭니다. 기존 테이블은 수정하지 않습니다.
3. Authentication에서 Anonymous Sign-ins를 켜야 학생 글쓰기가 됩니다. 읽기는 공개입니다.
4. Authentication에서 관리자 이메일/비밀번호 계정을 만드세요.
5. SQL 맨 아래 관리자 지정 문장의 이메일을 바꾸고 주석을 해제해 실행하세요. 이후 재로그인하세요. 프런트 코드에 비밀번호를 적지 않습니다.
6. 실제 공개 운영 전에는 익명 로그인 CAPTCHA/가입 제한과 게시물 도배 방지 대책을 추가하세요. 현재 SQL은 행 소유자와 글 길이를 검증하지만 빈도 제한은 포함하지 않습니다.

## 3. 실행 및 자료 등록
- VS Code에서 Live Server로 index.html을 여세요. 파일 더블클릭(file://)은 뉴스 fetch가 차단될 수 있습니다.
- 내신/수능, 학년/학기, 과목을 먼저 선택하고 홈의 관리자 모드로 들어가세요.
- 관리자는 선택된 과정에 강의/학습자료 URL과 교재 정보를 등록·삭제할 수 있습니다. 수정은 현재 삭제 후 재등록 방식입니다.
- 강의는 YouTube 주소 또는 공개 HTTPS mp4/webm 주소입니다. 자료는 접근 가능한 HTTPS 파일 주소입니다.
- 파일 직접 업로드 기능은 이번 묶음에 포함되지 않습니다. Supabase Storage에 별도로 업로드해 공개 URL을 등록하세요.
- 빈 과정에는 가짜 강의/교재 대신 빈 목록을 표시합니다. 모든 학년/학기에서 동일한 초기 과목 목록을 사용합니다. 과정별 과목 추가/이름 변경 UI는 아직 없습니다.

## 4. 뉴스 매일 자동 갱신
1. news-sources.json의 sources 배열에 사용이 허용된 RSS/Atom을 추가하세요:
   {"sources":[{"name":"언론사명","url":"사용 허가된 실제 HTTPS RSS 주소"}]}
   위 URL 설명은 예시 자리표시자입니다. 실제 주소로 바꾸세요.
2. GitHub 저장소에 모든 파일(.github 포함)을 올리세요.
3. Actions 실행과 Workflow의 저장소 쓰기 권한을 허용하세요.
4. Daily news → Run workflow를 실행해 성공을 확인하세요.
5. 저장소 변경 시 재배포되는 정적 호스팅을 연결하세요. 뉴스 커밋이 자동 배포되지 않는 호스팅에서는 매일 사이트에 반영되지 않습니다.
- 예약은 매일 한국시간 오전 6시입니다. GitHub 예약 실행은 지연/누락될 수 있으며 비활성 저장소에서는 중지될 수 있습니다.
- 현재 RSS 주소는 미입력입니다. 따라서 설정 전에는 자동 갱신이 작동하지 않습니다.
- 제목/출처/원문 링크만 표시하며, 기사 본문·사진은 수집하지 않습니다. 수집 실패 시 기존 파일과 기존 갱신 시간을 유지합니다.

## 5. 테마와 제한
- 도시/비행기 4개 시간대: 첨부 이미지 사용. 현재 기기 현지 시간에 맞춰 자동 전환합니다.
- 다른 8개는 임시 추상 SVG 풍경입니다. 요청한 산 정상/눈 마을/벤치/벚꽃길 등을 사실적으로 완성한 그림이 아닙니다. 같은 파일명으로 원하는 이미지 작업 후 코드의 확장자를 맞춰 교체하세요.
- 바다의 기존 원본 이미지는 첨부되지 않아 유지하지 못했습니다.
- 배경 움직임은 단일 이미지 시차 효과이고 실제 3D가 아닙니다.
- 테마 선택은 페이지 세션 상태이며 과목별 서버 저장/새로고침 복원은 아직 포함하지 않았습니다.
- 실제 계정 인증/서버 데이터/배포/동영상 코덱/뉴스 RSS 연결은 검증하지 못했습니다. JS 문법과 생성 파일 구조, 뉴스 정렬 로직만 점검했습니다.
- 오류가 나면 브라우저 콘솔 메시지와 Supabase 오류를 보내주세요.


# v2 변경사항 (위 구버전 제한 설명보다 이 내용이 우선)
- 사이트 표기를 Aurelia로 변경했습니다.
- 수능 과목: 국어/영어/수학/통합과학/통합사회. 수능은 학년·학기 공통으로 저장합니다.
- 시간대 버튼 제거. 기기 현재 시간으로 밝기/색감이 바뀝니다. 4개 별도 그림 대신 한 오일파스텔 그림에 시간별 조명을 적용합니다.
- 10개 배경을 새 오일파스텔 그림으로 교체했습니다.
- 과목별 기본 테마가 다르며 관리자가 과정/학년/학기/과목별 서버 저장할 수 있습니다. 학생에게 테마 변경 컨트롤은 표시되지 않습니다.
- 관리자만 최대 50MB 영상/자료를 파일 업로드하거나 URL 등록할 수 있습니다. 대용량 영상은 URL 방식을 사용하세요.
- server-setup.sql 전체를 다시 실행해야 테마 테이블과 업로드 버킷/정책이 추가됩니다. 기존 테이블의 레코드는 삭제하지 않습니다.
- 새 파일을 복사할 때 js/config.js의 기존 프로젝트 URL/공개 키를 유지하세요. 이 ZIP은 빈 설정으로 제공됩니다.
- 학생은 자료를 공개 열람할 수 있고 서버 업로드와 테마 변경 권한은 없습니다.
- 벚꽃/낙엽/눈/밤 유성 및 배경 시차는 CSS 2.5D 효과입니다. 실제 3D 모델이 아니며 움직임 줄이기 설정을 따릅니다.
- 테마 개별 설정 범위는 과목 페이지입니다. 홈/커뮤니티/서점은 흰색·샴페인 골드를 유지합니다.
- 실제 브라우저와 Supabase 연동은 이 환경에서 검증하지 못했습니다. JS 문법과 파일/로직 검사를 수행합니다.
