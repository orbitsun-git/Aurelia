# R6 기능 수정본 — 100개 배경 완성본 아님

## 적용
1. 저장소와 Supabase DB를 백업합니다. 원본 이미지와 js/config.js를 삭제하지 않습니다.
2. 기존 aurelia_subjects 테이블이 없다면 기존 setup/aurelia-update.sql을 검토해 먼저 적용합니다. 이미 있다면 재실행하지 않습니다.
3. setup/R6_subject_seed.sql을 최초 한 번 실행합니다. 기존 자료를 삭제하거나 다른 학기로 이동시키지 않습니다. 기본 여섯 과목의 표시 위치만 2학년 2학기로 등록합니다. 다른 학기에 실제 저장된 자료는 기존 DB에 남습니다.
4. ZIP 내용을 같은 위치에 합쳐 덮어씁니다. js/config.js는 본인 설정 유지. GitHub Actions 파일도 포함하되 기존 설정을 확인하세요.
5. Vercel 배포 후 새로고침합니다.

## 변경
- 기존 수능 과정 버튼 제거, 기존 서점 메뉴를 수능으로 통합.
- 수능 과목 국어·수학·영어·통합사회·통합과학·한국사 등록. 기존 표지 3장/교재 정보/링크 구조 유지.
- 학교 기본 과목은 2학년 2학기에만 표시. 다른 학기는 해당 학기에 DB에 등록한 과목만 표시.
- 관리자 과목 추가/수정/삭제. 과목 수정 시 subject_id를 유지해 자료 연결 유지. 과목 삭제는 자료를 연쇄 삭제하지 않으며 해당 과목 자료가 화면에서 숨겨질 수 있으므로 사전 백업 필요.
- 뉴스 설정은 뉴욕타임즈만 매일 수집. 저장된 뉴스도 뉴욕타임즈 링크만 남김. 기존 자동수집 워크플로 실행 필요; 새 기사 자체는 이번에 수집하지 않음.

## 이번에 완료되지 않은 요청
- 100개 테마 시간대별 개별 고해상도 이미지/정교한 테마별 애니메이션은 아직 제작 및 통합되지 않았습니다. 기존 77개 테마와 효과 파일 유지. 비교시트를 잘라서 완성 배경으로 위장하지 않았습니다.
- 사용자가 승인한 최신 리트리버 등 시안은 배포용 400장에 반영한 상태가 아닙니다.

## 검증과 한계
- JS 문법, 로컬 정적 참조, ZIP 무결성과 과목 선택 로직을 검사합니다.
- 실제 Supabase 권한·SQL 실행·관리자 로그인·이미지 업로드·Vercel 배포는 여기서 검증하지 못했습니다.
- 현재 갤러리 SQL 적용이 안 된 경우 기존 업로드 오류는 별도 해결이 필요합니다.
- 비밀 키·OAuth 토큰·서비스 역할 키는 GitHub에 저장하지 않습니다.
