# R7 배경 시안 적용 통합본

R6 수능/학기별 과목 기능에 100개 배경 선택과 시간대/효과 제어를 추가한 전체 코드입니다.
100개 고해상도 완성본이 아닙니다. 비교시트를 원래 픽셀 크기로 잘라 적용한 장면은 작은 크기 그대로 저장했으며, 큰 화면에서는 흐릴 수 있습니다. 정확한 이미지 크기와 제작 상태는 배경100_이미지상태.json에 기록했습니다. 시트 자동 분할이므로 장면 경계나 그림 속 번호가 남을 수 있습니다.

- 100개 가나다순 선택, 새벽/낮/노을/밤 및 자동 시간대.
- 독서실/러버덕/고래자리/먼 거리 운동장/금고와 바 구분/맞은편 좌석 버스 수정 시안 반영.
- 행복한 리트리버 거실은 승인된 낮 원본 한 장을 네 시간대에 공통 사용합니다. 다른 시간대로 새로 제작한 것이 아닙니다.
- 리트리버 바다는 최종 행복한 두 마리 디자인으로 재제작되지 않았으며 기존 시안입니다.
- 89번 버스는 맞은편 좌석 구도 시안이며 한국식 세부 구조 완성 재현을 검증하지 못했습니다.
- 삼괴고 낮은 사진을 참고한 개별 그림, 나머지 시간대는 비교시트입니다.
- 눈/낙엽/불티/물결/별 반짝임/빛줄기/종이학 형태의 단순 캔버스 효과. 실제 배경의 동물이나 산타·루돌프·시계·위성 오브젝트가 움직이는 것이 아닙니다.
- 기존 약한 포인터 시차 유지. 다층 분리 3D는 아닙니다. 효과 끄기/기기 모션 줄이기 지원.

적용: 저장소 백업 후 압축해제한 내용물을 같은 위치에 합칩니다. 기존 파일 전체 삭제 금지. js/config.js 본인 설정 유지. R6 SQL을 아직 적용하지 않았다면 R6 안내에 따라 최초 등록 SQL을 적용합니다. 배경만 변경하는 데 추가 SQL은 없습니다.

실제 브라우저 화면·Supabase 로그인/저장·Vercel 배포는 미검증입니다. 문법/400개 이미지 경로/파일 해독/ZIP 무결성 검사만 수행했습니다.
